# ClawdPet

[简体中文](README.zh-CN.md) · [English](README.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · **한국어**

바탕화면에 사는 픽셀 Clawd. AI 어시스턴트가 일하고 있으면 같이 바빠지고, AI가 일을 끝내면 두 손 들고 환호하고, AI가 당신의 답을 기다리고 있으면 팻말을 들고 발을 동동 구릅니다.

A pixel Clawd that lives on your Windows desktop and shows what your AI assistant is doing — busy, done, or waiting for you. Any AI assistant can change it with one command.

## 설치

먼저 Python 3가 있어야 합니다 ([python.org에서 다운로드](https://www.python.org/downloads/), 설치할 때 "Add python.exe to PATH"에 체크하세요).

1. 이 저장소를 다운로드해서 (오른쪽 위 Code → Download ZIP) 함부로 옮기지 않을 폴더에 압축을 풉니다
2. `start.bat`을 더블클릭하면 화면 오른쪽 아래에 Clawd가 나타납니다

**직접 하기 귀찮다면**: `AI-SETUP.md`를 쓰고 있는 AI(Codex, Claude Code, Cursor… 뭐든 괜찮아요)에게 주고 "AI-SETUP.md대로 ClawdPet 설치해 줘"라고 말하세요. 질문을 하나씩 하면서 바탕화면 바로가기도 만들어 주고, 상태가 자동으로 바뀌도록 연결까지 해 줍니다.

## AI가 Clawd에게 지금 뭘 하는지 알려 주기

어떤 AI 어시스턴트든 이 명령어 한 줄로 쓸 수 있습니다 (프로젝트 폴더 안에서 실행하면 프로젝트 이름은 자동으로 폴더 이름이 됩니다):

```
python "<펫을 설치한 곳>/pet.py" busy "로그인 페이지 작성 중"
```

| 상태 | 언제 쓰나요 | Clawd의 모습 |
|---|---|---|
| `urgent` 급해 | 당신의 답 / 결정 / 승인이 필요할 때 | 빨간 팻말을 들고 땀을 흘림 |
| `busy` 바빠 | 일하는 중 | 서서 흔들흔들 |
| `relaxed` 여유 | 할 일이 없을 때 | 엎드려서 차를 마심 |
| `cheer` 환호 | 한 부분을 끝냈을 때 | 두 손을 들고 별이 반짝반짝 |
| `sleep` 쿨쿨 | — | 새벽 1시부터 7시까지는 알아서 잠 |

- AI가 매번 기억하게 하고 싶다면: `AI-RULES.md`에 있는 부분을 AI의 설명 파일(`AGENTS.md`, `CLAUDE.md`…)에 붙여 넣으세요
- 완전 자동으로 하고 싶다면 (메시지를 보냄 → 바빠, AI가 끝냄 → 환호, AI가 당신을 기다림 → 급해): Claude Code와 Codex는 연결할 수 있어요. [`hooks/`](hooks/README.md)를 보세요
- Clawd 우클릭 → "최근 하는 일": AI가 최근에 Clawd에게 알려 준 내용을 어느 프로젝트인지, 몇 시인지와 함께 볼 수 있어요
- 상태는 알아서 만료돼요: "환호"는 15분, "바빠" / "급해"는 3시간 동안 아무도 업데이트하지 않으면 "여유"로 돌아갑니다

## Clawd 만지기

- **클릭**: 기본으로 Claude 데스크톱 앱이 열립니다. 우클릭 → "클릭해서 열기"에서 이렇게 바꿀 수 있어요: Clawdfield (연동됐을 때만 보여요) / 아무것도 안 열기 (Clawd가 폴짝 뛰고 한마디 함) / 직접 고른 아무 프로그램이나 웹 주소 (예: Codex, 다른 AI 앱)
- **드래그**: 어디로든 옮길 수 있고, 위치를 기억해요
- **우클릭**: 상태, 코디(옷장), 크기, 최근 하는 일, 클릭해서 열기, 연동, 부팅하면 자동으로 나오기, 정보

## 옷 갈아입기, 상태 추가하기: Clawd의 옷장

우클릭 → "코디" → "옷장 열기"를 누르면 옷장이 Clawd 바로 옆에 붙어서 열리고, 페이지는 네 개예요: **캐릭터**(누구인지), **외모**(뭘 입는지), **상태**(뭘 하는지), **성격**(어떤 성격인지). 외모에는 기본 세트 7벌이 있고, 체형(날씬이, 통통이, 키다리, 미니…), 귀, 꼬리, 손, 머리, 얼굴, 몸, 색을 하나씩 바꿀 수 있어요:

![기본 코디 7가지](docs/looks.png)

- **칸 위에 마우스를 올리면**: 바탕화면의 Clawd가 바로 입어 보고, 마우스를 떼면 원래대로 돌아와요. 클릭해야 진짜로 입습니다
- **마지막 칸 "＋ 새로"** 에는 세 가지 방법이 있어요:
  - Clawd가 3개 고르기: Clawd가 자기 취향대로 골라요. 마우스를 올리면 왜 좋은지 말해 줘요
  - ✨ AI가 3개 만들기: 원하는 느낌을 한 줄 적으세요 (비워 두면 알아서 만들어요)
  - ✍ 직접 그리기: 픽셀 그림판에서 왼쪽 클릭으로 그리고 오른쪽 클릭으로 지워요. 색은 직접 조절하고, 체형은 슬라이더 두 개(너비, 높이)로 바꿔요. 세트 전체는 "지금 코디를 세트로 저장"으로 저장할 수 있어요
- **Clawd가 고르기**와 **AI가 만들기**의 차이: Clawd가 고르기 = 자기 성격대로 골라요 (따로 요청할 필요 없음), AI가 만들기 = 당신이 쓴 요청대로 만들어요
- 이 두 가지는 컴퓨터에 이미 로그인된 Codex나 Claude Code를 빌려 써요 (Key 입력 필요 없음). 그리는 데 시간이 조금 걸려서 보통 십몇 초에서 1~2분 정도예요. 기다리는 동안 몇 초 지났는지 보여 주고, 기다리기 싫으면 "그만 기다리기"를 누르면 돼요. 둘 다 없으면 문장 하나를 복사해 주니까, 그걸 쓰고 있는 AI에게 붙여 넣으면 돼요
- **정리**: 기본 제공 항목은 숨겨지고 (다시 되살릴 수 있어요), 직접 만든 것과 AI가 만든 것은 진짜로 삭제돼요
- 칸 모서리의 작은 표시: ✎ 직접 만든 것 · ✨ AI가 만든 것 · Clawd 얼굴 = Clawd가 고른 것

**상태도 직접 추가할 수 있어요**: 옷장의 "상태" 페이지에서, 또는 우클릭 → "상태" → "＋ 상태 추가"에서요. 상태 하나 = 이름 + 어떤 자세를 쓸지 (급해 / 바빠 / 여유 / 환호 / 쿨쿨) + 그때 하는 말 몇 마디 + 그림판에서 Clawd 모습 바꾸기 (안 바꿔도 돼요): 작은 소품을 더하거나, "Clawd 색"으로 눈을 덮고 새 표정을 그리거나, 오른쪽 클릭으로 몇 칸 지워서 자세를 바꾸거나, 아예 "전부 지우기"로 처음부터 새로 그릴 수도 있어요. 기본 상태 5개가 하는 말도 바꿀 수 있어요. 우클릭 → "상태" → "⚄ 랜덤"을 누르면 아무거나 하나로 바뀌어요.

**랜덤 옷 갈아입기**: 우클릭 → "코디" → "⚄ 랜덤 옷 갈아입기"를 누르면 옷장의 세트(기본 7벌 + 직접 저장한 것) 중에서 지금과 다른 한 벌을 골라요. "정해진 시간마다 랜덤 옷"로 30분 / 1시간 / 3시간 / 하루마다 알아서 갈아입게 할 수도 있어요. 옷만 바뀌고 상태는 그대로예요 (상태 랜덤은 "상태" 안에 있어요).

Clawdfield와 연동되어 있다면 두 가지가 더 있어요: Clawdfield 옷장에서 "펫에게 복사"를 누른 다음, 여기서 우클릭 → "코디" → "Clawdfield 코디 붙여 넣기" (직접 그린 옷, 저장한 세트가 모두 넘어와요). 우클릭 → "코디" → "Clawdfield의 Clawd로 랜덤 교체"을 누르면 Clawdfield에 있는 다른 Clawd(각자 원래 모습 그대로)로 바뀌어요. 이 기능이 켜져 있으면 이쪽이 우선이에요.

## 언어

우클릭 → "언어": 简体中文 / 繁體中文 / English / 日本語 / 한국어. 기본으로 Windows 표시 언어를 따라가요. 바꾸면 Clawd가 한 번 다시 시작돼요. 언어를 추가하고 싶다면 `lang.json`의 모든 항목에 번역을 넣고, `lang.py`의 `LANGS`에 한 줄을 추가하세요.

## 성격

펫만 쓸 때도 Clawd에게는 자기 성격이 있어요: 처음 열 때 랜덤으로 하나가 정해져요 (햇살이, 츤데레, 느림보, 중2병 용사, 정리왕, 부끄럼쟁이, 먹보, 꼬마 철학자). 옷장의 "성격" 페이지에서 바꿀 수 있어요:

- **⚄ 랜덤**, 또는 기본 성격 중 하나를 클릭. 마우스를 올리면 Clawd가 어떤 성격인지 말해 줘요
- **직접 쓰기**: 이름 + 한 줄 설명을 쓰고 "저장"
- **✨ AI가 원하는 대로 하나 만들기**: 다 되면 먼저 입력칸에 채워지고, 당신이 보고 "저장"을 눌러야 바뀌어요
- **Clawd가 성격대로 대사 쓰기**: 이 성격에 맞춰 5개 상태(추가한 상태도)와 클릭됐을 때 하는 말을 전부 다시 써요. 먼저 보여 주고, 체크한 것만 바뀌어요
- "Clawd가 3개 고르기"도 이 성격대로 골라요

## Clawdfield와 연결되어 있을 때

Clawd의 캐릭터, 옷, 성격은 모두 Clawdfield를 따라가서, 양쪽이 달라지지 않게 옷장에서는 바꾸지 않아요. 코디를 바꾸려면: Clawdfield에서 Clawd를 우클릭 → "코디" → "펫에게 복사", 다시 돌아와서 우클릭 → "코디" → "Clawdfield 코디 붙여 넣기". 펫에서만 쓸 Clawd가 필요하면 Clawdfield에서 "데스크톱 펫 Clawd"를 새로 만들고, 꾸민 다음 복사해 오세요. 연결을 그만하고 싶으면: 우클릭 → "연동" → Clawdfield를 끄면 옷장이 다시 돌아와요.

## 캐릭터 바꾸기: 꼭 Clawd가 아니어도 돼요

기본은 Clawd지만, 펫은 어떤 캐릭터로도 바꿀 수 있어요: 고양이, 슬라임 한 덩이, 내가 쓰는 AI 어시스턴트의 모습도 좋아요. 우클릭 → "코디" → "캐릭터 바꾸기…", 또는 옷장의 "캐릭터" 페이지에서요:

- **어떻게 나누나요**: 옷을 다 벗겨도 그대로 Clawd인 것(여우 Clawd, 보라 냥이, 아쿠아 토끼…)은 "세트"이고 "외모" 페이지에 있어요. 몸 윤곽부터 다른 것만 "캐릭터"예요
- **"＋ 새로"**: ✍ 직접 한 마리 그리기 (점선 상자가 대략 Clawd 크기이고, 발은 상자 바닥에 딛게 해요. 가장 많이 쓴 색이 그 캐릭터의 메인 색이 돼요) / ✨ AI가 3마리 그리기 / Clawd가 3마리 골라 주기
- **자세 5개는 자동으로 맞춰져요**: 팻말 든 급해, 바빠, 차 마시는 여유, 별이 뜨는 환호, Z가 뜨는 쿨쿨. 마음에 안 드는 게 있으면 캐릭터 페이지 아래쪽의 작은 그림 줄을 클릭해서 그림판에서 직접 고칠 수 있어요 (예: 쿨쿨일 때 눈 감기기). 망쳤으면 "자동으로 되돌리기"를 누르세요
- **옷도 그대로 입을 수 있어요**: 모자, 귀, 손에 든 것은 캐릭터 크기에 맞춰 씌워져요. "색"은 그 캐릭터의 메인 색을 바꿔요. 체형도 조절할 수 있어요
- 직접 만든 상태에서 바꾼 모습은 그걸 그린 캐릭터에서만 쓰여서, 캐릭터를 바꿔도 엉키지 않아요
- 클릭하면 열리는 것도 바꿀 수 있어요 (우클릭 → "클릭해서 열기" → 다른 프로그램 선택). 예를 들어 Codex나 자주 쓰는 AI 앱으로요
- 코드에서 통째로 바꾸고 싶다면: Clawd를 그리는 건 `clawd_pet.py` 안의 `clawd()`, 다른 캐릭터를 그리는 건 `char_cells()`예요. 다 고친 뒤에는 라이선스에 따라 무엇을 바꿨는지 꼭 적어 주세요

## 다른 Clawd 프로그램과 연결하기

ClawdPet, 작업대 "Clawdfield", 무전기 채팅 창 "Clawkie"는 각각 따로 쓸 수 있어요. 무엇을 설치하든 Clawd가 알아서 찾아내고 (사용자 폴더 안의 "명함" `.clawd\`를 이용해요), 처음 발견했을 때 자동으로 연결되니까 따로 설정할 필요가 없어요. **연결되어야 관련 메뉴가 나타나요**:

| 설치한 것 | Clawd는 이렇게 돼요 |
|---|---|
| 펫만 | 상태, 옷장, "최근 하는 일" 모두 쓸 수 있어요. 클릭하면 Claude 앱 (또는 직접 고른 것)이 열려요 |
| ＋ Clawdfield | 우클릭 메뉴에 "Clawdfield 열기", "Clawdfield 코디 붙여 넣기", "Clawdfield의 Clawd로 랜덤 교체"이 생겨요. "클릭해서 열기"에서 Clawdfield를 고를 수 있어요 (켜져 있지 않으면 대신 켜 줘요) |
| ＋ Clawkie | Clawd가 미니 무전기를 들어요: 무전기를 클릭하거나 Clawd를 더블클릭 = Clawkie 불러오기, 길게 누르기 = 누르고 말하기 |
| 셋 다 | Clawd 클릭 = 직접 고른 것 (Claude / Clawdfield), 무전기 클릭 = Clawkie |

우클릭 → "연동"에서 직접 켜고 끌 수 있어요. Clawdfield를 찾지 못했을 때 켜면 어디에 설치했는지 고르라고 물어봐요. 끄면 다시는 자동으로 연결되지 않아요.

Clawdfield와 Clawkie는 모두 제작자의 다른 작품이고, [제작자의 GitHub](https://github.com/Miaomiaomeowmeow)에 올라갈 예정이에요. 지금 안 보인다면 조금 지나면 올라올 거예요.
