# ClawdPet

[简体中文](README.zh-CN.md) · [English](README.md) · [繁體中文](README.zh-TW.md) · **日本語** · [한국어](README.ko.md)

デスクトップに住むピクセルの Clawd。AI アシスタントが作業中なら一緒に忙しそうにして、AI が終わったら両手を上げて大喜び、AI があなたの返事を待っているときはプラカードを掲げてあせります。

A pixel Clawd that lives on your Windows desktop and shows what your AI assistant is doing — busy, done, or waiting for you. Any AI assistant can change it with one command.

![5 つの状態：あせあせ、いそがしい、のんびり、ばんざい、おやすみ](docs/states.png)

## インストール

まず Python 3 が必要です（[python.org からダウンロード](https://www.python.org/downloads/)。インストール時に「Add python.exe to PATH」にチェックを入れてください）。

1. このリポジトリをダウンロード（右上の Code → Download ZIP）して、あまり動かさないフォルダに展開します
2. `start.bat` をダブルクリックすると、画面の右下に Clawd が現れます

**自分でやるのが面倒なら**：`AI-SETUP.md` をお使いの AI（Codex、Claude Code、Cursor……どれでも OK）に渡して、「AI-SETUP.md のとおりに ClawdPet をインストールして」と頼んでください。質問を 1 つずつしながら、デスクトップのショートカット作成や、状態の自動切り替えの設定までやってくれます。

## AI から Clawd に「今なにしてるか」を伝える

どんな AI アシスタントでも、このコマンド 1 行で使えます（プロジェクトのフォルダの中で実行すると、プロジェクト名にはフォルダ名が自動で使われます）：

```
python "<ペットのインストール先>/pet.py" busy "ログインページを作成中"
```

| 状態 | 使うとき | Clawd の様子 |
|---|---|---|
| `urgent` あせあせ | あなたの返事・決定・承認が必要 | 赤いプラカードを掲げて、汗をかく |
| `busy` いそがしい | 作業している | 立ってゆらゆら |
| `relaxed` のんびり | 特に何もない | 寝そべってお茶を飲む |
| `cheer` ばんざい | ひと区切りついた | 両手を上げて、星がキラキラ |
| `sleep` おやすみ | — | 夜中の 1 時から 7 時までは自分で寝る |

- AI に毎回覚えておいてほしいとき：`AI-RULES.md` の一節を、AI の説明ファイル（`AGENTS.md`、`CLAUDE.md`……）に貼り付けます
- 全自動にしたいとき（メッセージを送る → いそがしい、AI が終わる → ばんざい、AI があなたを待つ → あせあせ）：Claude Code と Codex なら接続できます。[`hooks/`](hooks/README.md) を見てください
- Clawd を右クリック →「最近やってること」：AI が最近 Clawd に伝えた内容を、どのプロジェクトか・何時かと一緒に見られます
- 状態は自動で期限切れになります：「ばんざい」は 15 分、「いそがしい」/「あせあせ」は 3 時間だれも更新しなければ、「のんびり」に戻ります

## Clawd とあそぶ

- **クリック**：最初は Claude デスクトップアプリが開きます。右クリック →「クリックで開く」で次のように変えられます：Clawdfield（連携しているときだけ出てきます）/ 何も開かない（Clawd がぴょんと跳ねてひとこと話す）/ 自分で選んだ好きなプログラムや URL（たとえば Codex やほかの AI アプリ）
- **ドラッグ**：どこにでも動かせて、場所を覚えてくれます
- **右クリック**：状態、コーデ（クローゼット）、サイズ、最近やってること、クリックで開く、連携、PC 起動時に出てくる、このアプリについて

## 着替え・状態の追加：Clawd のクローゼット

右クリック →「コーデ」→「クローゼットを開く」で、Clawd のすぐ横にクローゼットが開きます。ページは 4 つ：**キャラ**（だれか）、**見た目**（何を着るか）、**状態**（何をしているか）、**性格**（どんな性格か）。見た目には内蔵のフルセットが 7 つあり、ほかにも体型（ほっそり、ぽっちゃり、のっぽ、ミニ……）、耳、しっぽ、手、頭、顔、体、色を 1 つずつ着せ替えられます：

![内蔵の 7 つの見た目](docs/looks.png)

- **マスにマウスを乗せる**：デスクトップの Clawd がすぐに試着して、マウスを離すと元に戻ります。クリックして初めて本当に着替えます
- **最後のマス「＋ 新規」** には 3 つの方法があります：
  - Clawd が3つ選ぶ：Clawd が自分の好みで選びます。マウスを乗せると、なぜ気に入ったのか教えてくれます
  - ✨ AI が3つ作る：どんなのがいいか一言書きます（空欄ならおまかせ）
  - ✍ 自分で描く：ピクセルのお絵かきボードで、左クリックで描いて右クリックで消します。色も自分で調整でき、体型は 2 本のスライダー（幅・高さ）で変えられます。フルセットは「今のコーデをセットで保存」で保存できます
- **Clawd が選ぶ**と **AI が作る**の違い：Clawd が選ぶ = 自分の性格に合わせて選ぶ（あなたが注文しなくていい）、AI が作る = あなたが書いた注文どおりに作る
- この 2 つは、パソコンにすでにログインしている Codex か Claude Code を借ります（Key の入力は不要）。描くのには少し時間がかかり、ふつうは十数秒〜1、2 分ほどです。待っている間は何秒たったかが表示され、待ちたくなければ「もう待たない」を押せます。どちらも入っていない場合は、一文がコピーされるので、それを自分の AI に貼り付ければ OK です
- **整理**：内蔵のものは非表示になります（元に戻せます）。自分で作ったもの・AI が作ったものは本当に削除されます
- マスの角の小さなマーク：✎ あなたが作った · ✨ AI が作った · Clawd の顔 = Clawd が選んだ

**状態も自分で追加できます**：クローゼットの「状態」ページか、右クリック →「状態」→「＋ 状態を追加」から。1 つの状態 = 名前 + どのポーズを使うか（あせあせ / いそがしい / のんびり / ばんざい / おやすみ）+ そのときに話すいくつかのセリフ + お絵かきボードで Clawd の見た目を変える（変えなくても OK）：小物を足したり、「Clawd 色」で目を塗りつぶして新しい表情を描いたり、右クリックで何マスか消してポーズを変えたり、いっそ「全部消す」で一から描き直すこともできます。内蔵の 5 つの状態のセリフも変えられます。右クリック →「状態」→「⚄ ランダム」で適当に 1 つに切り替わります。

**ランダムでお着替え**：右クリック →「コーデ」→「⚄ ランダムでお着替え」で、クローゼットのフルセット（内蔵の 7 つ + 自分で保存したもの）から今と違う 1 着を選びます。「定期的にランダムお着替え」なら、30 分 / 1 時間 / 3 時間 / 1 日ごとに自動で着替えます。変わるのは服だけで、状態はそのままです（状態のランダムは「状態」の中にあります）。

Clawdfield と連携している場合は、さらに 2 つ使えます：Clawdfield のクローゼットで「ペットにコピー」を押してから、こちらで右クリック →「コーデ」→「Clawdfieldのコーデを貼り付け」（自分で描いた服も、保存したフルセットも全部移せます）。右クリック →「コーデ」→「Clawdfieldの Clawd にランダムで交代」では、Clawdfield にいるほかの Clawd（それぞれの見た目のまま）に変わります。これがオンのときはこちらが優先されます。

## 言語

右クリック →「言語」：简体中文 / 繁體中文 / English / 日本語 / 한국어。最初は Windows の表示言語に合わせます。切り替えると Clawd が一度再起動します。言語を追加したいときは、`lang.json` の各項目に翻訳を足して、`lang.py` の `LANGS` に 1 行追加してください。

## 性格

ペットだけで使うときも、Clawd には自分の性格があります：最初に開いたときにランダムで 1 つ決まります（おひさま、ツンデレ、のんびり屋、中二勇者、きれい好き、人見知り、くいしんぼう、ちび哲学者）。クローゼットの「性格」ページで変えられます：

- **⚄ ランダム**、または内蔵のものをクリック。マウスを乗せると、Clawd がどんな性格か話してくれます
- **自分で書く**：名前 + ひとことの説明を書いて「保存」
- **✨ AI にリクエストどおり作ってもらう**：できたものはまず入力欄に入り、あなたが確認して「保存」を押したときだけ切り替わります
- **Clawd に性格でセリフを書いてもらう**：この性格に合わせて、5 つの状態（追加した状態も）とクリックされたときのセリフを全部書き直します。先に見せてくれて、チェックしたものだけが入れ替わります
- 「Clawd が3つ選ぶ」もこの性格に合わせて選びます

## Clawdfield と連携しているとき

Clawd のキャラ・服・性格はすべて Clawdfield に合わせるので、両方がズレないようにクローゼットでは変えません。コーデを変えるには：Clawdfield で Clawd を右クリック →「コーデ」→「ペットにコピー」、戻ってきて右クリック →「コーデ」→「Clawdfieldのコーデを貼り付け」。デスクトップペット専用の Clawd がほしいときは、Clawdfield で新しく「デスクトップペット Clawd」を作って、着せ替えてからコピーしてください。連携をやめたいときは：右クリック →「連携」→ Clawdfield をオフにすると、クローゼットが戻ってきます。

## キャラを変える：Clawd じゃなくてもいい

最初は Clawd ですが、ペットはどんなキャラにも変えられます：ネコでも、スライムでも、自分の AI アシスタントの姿でも OK。右クリック →「コーデ」→「キャラを変える…」、またはクローゼットの「キャラ」ページから：

- **分け方**：服を全部脱いだら Clawd に戻るもの（キツネ Clawd、むらさきニャンコ、みずいろうさぎ……）は「セット」で、「見た目」ページにあります。体の輪郭から違うものだけが「キャラ」です
- **「＋ 新規」**：✍ 自分で 1 体描く（点線の枠がだいたい Clawd の大きさで、足は枠の底に置きます。いちばん多く使った色がそのキャラのメインカラーになります）/ ✨ AI が 3 体描く / Clawd が 3 体選んでくれる
- **5 つのポーズは自動で用意されます**：プラカードを掲げるあせあせ、いそがしい、お茶を飲むのんびり、星が出るばんざい、Z が出るおやすみ。気に入らないものがあれば、キャラページの下にある小さな絵の列をクリックすると、お絵かきボードで自分で直せます（たとえばおやすみのときは目を閉じる）。失敗したら「自動に戻す」を押してください
- **服もそのまま着られます**：帽子、耳、手に持つものはキャラの大きさに合わせて付きます。「色」で変わるのはそのキャラのメインカラーです。体型も調整できます
- 自分で作った状態で変えた見た目は、それを描いたキャラにだけ使われるので、キャラを変えても崩れません
- クリックで開くものも変えられます（右クリック →「クリックで開く」→ 別のプログラムを選ぶ）。たとえば Codex や、よく使う AI アプリに
- コードから丸ごと変えたいとき：Clawd を描いているのは `clawd_pet.py` の `clawd()`、ほかのキャラを描いているのは `char_cells()` です。書き換えたら、ライセンスに従って何を変えたかを明記するのを忘れずに

## ほかの Clawd アプリとつなげる

ClawdPet、ワークベンチ「Clawdfield」、トランシーバー風チャットウィンドウ「Clawkie」は、それぞれ単体でも使えます。どれをインストールしても Clawd が自分で見つけて（ユーザーフォルダの中の「名刺」`.clawd\` を使います）、最初に見つけたときに自動で連携するので、設定はいりません。**連携してはじめて、関係するメニュー項目が表示されます**：

| インストールしたもの | Clawd はどうなる？ |
|---|---|
| ペットだけ | 状態、クローゼット、「最近やってること」がすべて使えます。クリックで Claude アプリ（または自分で選んだもの）が開きます |
| ＋ Clawdfield | 右クリックに「Clawdfieldを開く」「Clawdfieldのコーデを貼り付け」「Clawdfieldの Clawd にランダムで交代」が増えます。「クリックで開く」で Clawdfield を選べます（起動していなければ代わりに起動します） |
| ＋ Clawkie | Clawd がミニトランシーバーを持ちます：トランシーバーをクリックするか Clawd をダブルクリック = Clawkie を呼び出す、長押し = 押して話す |
| 3 つ全部 | Clawd をクリック = 自分で選んだもの（Claude / Clawdfield）、トランシーバーをクリック = Clawkie |

右クリック →「連携」で手動でオン・オフできます。Clawdfield が見つからないときにオンにすると、インストール先を選ぶように聞かれます。オフにすると、もう自動では連携しません。

Clawdfield と Clawkie はどちらも作者のほかの作品で、[作者の GitHub](https://github.com/Miaomiaomeowmeow) で公開する予定です。まだ見当たらなければ、しばらくしたら公開されます。

## ファイル

| ファイル | 中身 |
|---|---|
| `clawd_pet.py` | Clawd 本体（Python に最初から入っているものだけを使うので、ほかに何もインストール不要） |
| `pet.py` | Clawd の状態を変える小さなコマンド（状態、服、色、フルセットの追加もできます） |
| `wardrobe.py` | クローゼットのウィンドウ |
| `lang.py` / `lang.json` | 多言語対応（画面の文言と翻訳） |
| `start.bat` | ダブルクリックで起動 |
| `AI-SETUP.md` / `AI-RULES.md` | あなたの AI が読むもの：インストールガイド / 説明ファイルに貼り付ける一節 |
| `hooks/` | 会話に合わせて自動で変わるようにする接続方法 |
| `status.json` / `settings.json` / `recent.json` | 動いている間に自動で作られます：今の状態 / あなたの設定 / 最近の数件 |

Clawd はパソコンのユーザーフォルダに「名刺」（`.clawd\pet.json`）を置き、自分がどこにインストールされているかを書いておきます。Clawdfield はこれを頼りに Clawd を見つけます。
