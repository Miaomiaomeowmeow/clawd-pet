# 小克桌宠 ClawdPet

**简体中文** · [English](README.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

桌面上的一只像素小克。你的 AI 助手在干活，它就跟着忙；AI 做完了，它举手欢呼；AI 在等你回话，它举牌子着急。

A pixel Clawd that lives on your Windows desktop and shows what your AI assistant is doing — busy, done, or waiting for you. Any AI assistant can change it with one command.

![五种状态：着急、忙碌、悠闲、欢呼、睡觉](docs/states.png)

## 装上

要先有 Python 3（[python.org 下载](https://www.python.org/downloads/)，安装时勾上「Add python.exe to PATH」）。

1. 下载这个仓库（右上角 Code → Download ZIP），解压到一个你不会乱动的文件夹
2. 双击 `start.bat`，小克出现在屏幕右下角

**懒得自己弄**：把 `AI-SETUP.md` 丢给你的 AI（Codex、Claude Code、Cursor……都行），说「照 AI-SETUP.md 帮我装小克桌宠」。它会一题一题问你，帮你建桌面快捷方式、接好自动变状态。

## 让 AI 告诉小克在做什么

任何 AI 助手都能用这一条命令（在项目文件夹里跑，项目名自动用文件夹的名字）：

```
python "<桌宠装在哪>/pet.py" busy "在写登录页"
```

| 状态 | 什么时候用 | 小克的样子 |
|---|---|---|
| `urgent` 着急 | 要你回话 / 拍板 / 点同意 | 举红牌子，冒汗 |
| `busy` 忙碌 | 正在干活 | 站着晃 |
| `relaxed` 悠闲 | 没事 | 趴着喝茶 |
| `cheer` 欢呼 | 做完一块 | 举手，冒星星 |
| `sleep` 睡觉 | — | 半夜 1 点到 7 点自己睡 |

- 想让 AI 每次都记得：把 `AI-RULES.md` 里那段贴进它的说明文件（`AGENTS.md`、`CLAUDE.md`……）
- 想全自动（你发消息 → 忙碌，AI 做完 → 欢呼，AI 等你 → 着急）：Claude Code 和 Codex 能接，见 [`hooks/`](hooks/README.md)
- 右键小克 →「最近在做」：看 AI 最近告诉小克的话，哪个项目、几点
- 状态会自己过期：欢呼 15 分钟、忙碌 / 着急 3 小时没人更新，就变回悠闲

## 摸小克

- **点一下**：默认打开 Claude 桌面应用。右键 →「点一下打开」能改成：工作台（连上了才有这项）/ 什么都不打开（小克跳一下、说句话）/ 你自己选的任何程序或网址（例如 Codex、别的 AI 应用）
- **拖**：挪到哪都行，会记住
- **右键**：状态、造型（衣柜）、大小、最近在做、点一下打开什么、联动、开机自动出现、关于

## 换衣服、加状态：小克的衣柜

右键 → 造型 →「打开衣柜」，衣柜就贴在小克旁边，分四页：**形象**（是谁）、**外表**（穿什么）、**状态**（在干嘛）、**性格**（什么脾气）。外表里内置 7 套整套，还有体型（瘦瘦、胖嘟嘟、高个子、迷你……）、耳朵、尾巴、手上、头上、脸上、身上、颜色可以一件一件换：

![七套内置造型](docs/looks.png)

- **鼠标放到格子上**：桌面上的小克马上试穿，移开就换回来；点一下才真的穿上
- **最后一格「＋ 新的」**，三条路：
  - 小克挑 3 个：小克按自己的口味挑，鼠标放上去它会说为什么喜欢
  - ✨ AI 做 3 个：写一句想要什么样（空着就随便做）
  - ✍ 自己做：像素画板，左键画、右键擦；颜色自己调；体型拖两根滑杆（宽、高）；整套可以「把现在这身存成整套」
- **小克挑**和 **AI 做**的区别：小克挑 = 按它自己的性格挑（不用你说要求）；AI 做 = 照你写的要求做
- 这两个会借你电脑上已经登录的 Codex 或 Claude Code（不用填 Key）。画东西要一点时间，一般十几秒到一两分钟，等的时候会显示等了几秒，不想等可以点「不等了」。都没装的话，会复制一句话，你贴给自己的 AI 就行
- **整理**：内置的藏起来（能恢复），自己做的、AI 做的真删
- 格子角上的小标：✎ 你做的 · ✨ AI 做的 · 小克的脸 = 小克挑的

**状态也能自己加**：衣柜的「状态」页，或者右键 → 状态 →「＋ 加一个新状态」。一个状态 = 名字 + 用哪种姿势（着急 / 忙碌 / 悠闲 / 欢呼 / 睡觉）+ 这时说的几句话 + 在画板上改小克的样子（可以不改）：加个小道具、用「小克色」把眼睛涂掉再画个新表情、右键擦掉几格改姿势，甚至「整只擦掉」从头画一只。内置的 5 个状态说的话也能改。右键 → 状态 →「⚄ 随机一个」随便换一个。

**随机换一身**：右键 → 造型 →「⚄ 随机换一身」，从衣柜里的整套（内置 7 套 + 你自己存的）里挑一身跟现在不一样的；「定时随机换一身」可以每 30 分钟 / 1 小时 / 3 小时 / 每天自己换。只换衣服，状态不变（状态的随机在「状态」里）。

连上工作台的话，还多两样：在工作台衣柜里点「复制给桌宠」，再到这里右键 → 造型 →「粘贴工作台的造型」（自己画的衣服、存的整套都搬过来）；右键 → 造型 →「随机换成工作台里的小克」，换成你工作台里别的小克（它们各自的样子）；这个开着的时候优先用它。

## 语言

右键 →「语言」：简体中文 / 繁體中文 / English / 日本語 / 한국어，默认跟着 Windows 的显示语言。换完小克会重启一下。想加一种语言：在 `lang.json` 每一条里加上翻译，再在 `lang.py` 的 `LANGS` 里加一行。

## 性格

只用桌宠的时候，小克也有自己的性格：第一次打开会随机给它一个（小太阳、嘴硬心软、慢吞吞、中二勇者、整理控、社恐、小吃货、小哲学家）。衣柜的「性格」页能换：

- **⚄ 随机一个**，或者点内置的那几个；鼠标放上去，小克会说它是什么样的
- **自己写**：名字 + 一句话描述，点「存」
- **✨ 让 AI 按你的要求写一个**：写好先填在框里，你看过点「存」才换上
- **让小克按性格写话**：照这个性格，把 5 个状态（还有你加的状态）和被点一下时说的话都重写一遍，写好先给你看，勾上的才换
- 「小克挑 3 个」也是照这个性格挑的

## 连着工作台的时候

小克的形象、衣服、性格都跟工作台走，衣柜里就不改了，免得两边不一样。换造型：在工作台里右键小克 → 造型 →「复制给桌宠」，再回来右键 → 造型 →「粘贴工作台的造型」。想要一只只在桌宠上用的小克，就在工作台里新建一只「桌宠小克」，打扮好再复制过来。不想连了：右键 → 联动 → 把工作台关掉，衣柜就回来了。

## 换形象：不一定是小克

默认是小克，但桌宠可以换成任何角色：一只猫、一团史莱姆、你自己 AI 助手的样子都行。右键 → 造型 →「换形象…」，或者衣柜的「形象」页：

- **怎么分**：把衣服全脱掉还是小克的（狐狸小克、紫色猫猫、水青兔兔……）算「整套」，在「外表」页；连身子轮廓都不一样的才算「形象」
- **「＋ 新的」**：✍ 自己画一只（虚线框差不多是小克的大小，脚踩在框底；用得最多的颜色就是它的主色）/ ✨ AI 画 3 只 / 小克帮你挑 3 只
- **5 个姿势自动配好**：着急举牌、忙碌、悠闲喝茶、欢呼冒星星、睡觉冒 Z。哪个不满意，点形象页下面那排小图，就能在画板上自己改（比如睡觉时把眼睛闭上）；改坏了点「换回自动的」
- **衣服照样能穿**：帽子、耳朵、手上拿的会按它的大小套上去；「颜色」换的是它的主色；体型也能调
- 自己写的状态里改过的样子，只在画它的那个形象上用，换形象不会乱
- 点一下打开什么也能换（右键 →「点一下打开」→ 选一个别的程序），比如换成 Codex 或你常用的 AI 应用
- 想从代码层面整个改：画小克的是 `clawd_pet.py` 里的 `clawd()`，画别的形象的是 `char_cells()`；改完记得照许可写清改了什么

## 跟别的小克程序连起来

小克桌宠、「今日小克终未地」工作台、「克讲机」小对讲机窗口，三样各自能单独用。装了哪样，小克自己就会找到（靠用户文件夹里的「名片」`.clawd\`），第一次发现就自动连上，不用再设置；**连上了，相关的东西才会出现在菜单里**：

| 装了什么 | 小克会怎样 |
|---|---|
| 只有桌宠 | 状态、衣柜、最近在做都能用；点一下打开 Claude 应用（或你选的） |
| ＋ 工作台 | 右键多了「打开工作台」「粘贴工作台的造型」「随机换成工作台里的小克」；「点一下」可以选工作台（没开着就帮它开） |
| ＋ 克讲机 | 小克手里拿上迷你对讲机：点对讲机或双击小克 = 叫出克讲机，长按 = 按住说话 |
| 三样都有 | 点小克 = 你选的（Claude / 工作台），点对讲机 = 克讲机 |

右键 → 联动 可以手动开关：工作台找不到时打开开关会让你选它装在哪；关掉了就不会再自动连上。

工作台和克讲机都是作者的其他作品，会发在 [作者的 GitHub](https://github.com/Miaomiaomeowmeow)；现在还没看到的话，过段时间就会发上来。

## 文件

| 文件 | 是什么 |
|---|---|
| `clawd_pet.py` | 小克本体（只用 Python 自带的东西，不用装别的） |
| `pet.py` | 让小克变状态的小命令（也能加状态、衣服、颜色、整套） |
| `wardrobe.py` | 衣柜窗口 |
| `lang.py` / `lang.json` | 多语言（界面上的话和翻译） |
| `start.bat` | 双击启动 |
| `AI-SETUP.md` / `AI-RULES.md` | 给你的 AI 看的：安装向导 / 贴进说明文件的那段 |
| `hooks/` | 自动跟着对话变的接法 |
| `status.json` / `settings.json` / `recent.json` | 运行时自己生成：现在的状态 / 你的设置 / 最近几条 |

小克在你电脑的用户文件夹里放一张「名片」（`.clawd\pet.json`），写着自己装在哪，工作台靠它找到小克。
