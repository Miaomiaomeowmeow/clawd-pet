# 小克桌寵 ClawdPet

[简体中文](README.zh-CN.md) · [English](README.md) · **繁體中文** · [日本語](README.ja.md) · [한국어](README.ko.md)

桌面上的一隻像素小克。你的 AI 助理在工作，它就跟著忙；AI 做完了，它舉手歡呼；AI 在等你回覆，它舉牌子著急。

A pixel Clawd that lives on your Windows desktop and shows what your AI assistant is doing — busy, done, or waiting for you. Any AI assistant can change it with one command.

![五種狀態：著急、忙碌、悠閒、歡呼、睡覺](docs/states.png)

## 安裝

要先有 Python 3（[到 python.org 下載](https://www.python.org/downloads/)，安裝時勾選「Add python.exe to PATH」）。

1. 下載這個儲存庫（右上角 Code → Download ZIP），解壓縮到一個你不會亂動的資料夾
2. 按兩下 `start.bat`，小克就會出現在螢幕右下角

**懶得自己弄**：把 `AI-SETUP.md` 丟給你的 AI（Codex、Claude Code、Cursor……都可以），說「照 AI-SETUP.md 幫我安裝小克桌寵」。它會一題一題問你，幫你建好桌面捷徑、接好自動切換狀態。

## 讓 AI 告訴小克在做什麼

任何 AI 助理都能用這一行指令（在專案資料夾裡執行，專案名稱會自動用資料夾的名字）：

```
python "<桌寵裝在哪>/pet.py" busy "在寫登入頁"
```

| 狀態 | 什麼時候用 | 小克的樣子 |
|---|---|---|
| `urgent` 著急 | 需要你回覆 / 拍板 / 按同意 | 舉紅牌子，冒汗 |
| `busy` 忙碌 | 正在工作 | 站著晃 |
| `relaxed` 悠閒 | 沒事 | 趴著喝茶 |
| `cheer` 歡呼 | 做完一部分 | 舉手，冒星星 |
| `sleep` 睡覺 | — | 半夜 1 點到 7 點自己睡 |

- 想讓 AI 每次都記得：把 `AI-RULES.md` 裡那段貼進它的說明檔（`AGENTS.md`、`CLAUDE.md`……）
- 想全自動（你傳訊息 → 忙碌，AI 做完 → 歡呼，AI 等你 → 著急）：Claude Code 和 Codex 可以接，見 [`hooks/`](hooks/README.md)
- 右鍵小克 →「最近在做」：看 AI 最近告訴小克的話、是哪個專案、幾點
- 狀態會自己過期：歡呼 15 分鐘、忙碌 / 著急 3 小時沒人更新，就會變回悠閒

## 摸摸小克

- **點一下**：預設開啟 Claude 桌面應用程式。右鍵 →「點一下打開」可以改成：工作台（連上了才有這項）/ 什麼都不開（小克跳一下、說句話）/ 你自己選的任何程式或網址（例如 Codex、其他 AI 應用程式）
- **拖曳**：放到哪裡都可以，會記住位置
- **右鍵**：狀態、造型（衣櫃）、大小、最近在做、點一下打開、連動、開機自動出現、關於

## 換衣服、加狀態：小克的衣櫃

右鍵 →「造型」→「打開衣櫃」，衣櫃就會貼在小克旁邊，分成四頁：**形象**（是誰）、**外表**（穿什麼）、**狀態**（在幹嘛）、**性格**（什麼脾氣）。外表裡內建 7 套整套造型，還有體型（瘦瘦、胖嘟嘟、高個子、迷你……）、耳朵、尾巴、手上、頭上、臉上、身上、顏色可以一件一件換：

![七套內建造型](docs/looks.png)

- **滑鼠移到格子上**：桌面上的小克馬上試穿，移開就換回來；點一下才會真的穿上
- **最後一格「＋ 新的」**，有三條路：
  - 小克挑 3 個：小克照自己的喜好挑，滑鼠移上去它會說為什麼喜歡
  - ✨ AI 做 3 個：寫一句想要什麼樣子（空著就隨便做）
  - ✍ 自己畫：像素畫布，左鍵畫、右鍵擦；顏色自己調；體型拖兩根滑桿（寬、高）；整套可以用「把現在這身存成整套」
- **小克挑**和 **AI 做**的差別：小克挑 = 照它自己的性格挑（不用你提要求）；AI 做 = 照你寫的要求做
- 這兩個會借用你電腦上已經登入的 Codex 或 Claude Code（不用填 Key）。畫東西要一點時間，一般十幾秒到一兩分鐘，等的時候會顯示等了幾秒，不想等可以點「不等了」。如果都沒裝，它會幫你複製一句話，你貼給自己的 AI 就行
- **整理**：內建的會藏起來（可以還原），自己做的、AI 做的會真的刪除
- 格子角落的小標記：✎ 你做的 · ✨ AI 做的 · 小克的臉 = 小克挑的

**狀態也能自己加**：衣櫃的「狀態」頁，或者右鍵 →「狀態」→「＋ 加一個新狀態」。一個狀態 = 名字 + 用哪種姿勢（著急 / 忙碌 / 悠閒 / 歡呼 / 睡覺）+ 這時說的幾句話 + 在畫布上改小克的樣子（可以不改）：加個小道具、用「小克色」把眼睛塗掉再畫個新表情、右鍵擦掉幾格改姿勢，甚至「整隻擦掉」從頭畫一隻。內建 5 個狀態說的話也能改。右鍵 →「狀態」→「⚄ 隨機一個」隨便換一個。

**隨機換一身**：右鍵 →「造型」→「⚄ 隨機換一身」，從衣櫃裡的整套（內建 7 套 + 你自己存的）挑一身跟現在不一樣的；「定時隨機換一身」可以每 30 分鐘 / 1 小時 / 3 小時 / 每天自己換。只換衣服，狀態不變（狀態的隨機在「狀態」裡）。

連上工作台的話，還多兩項：在工作台的衣櫃裡點「複製給桌寵」，再到這裡右鍵 →「造型」→「貼上工作台的造型」（自己畫的衣服、存的整套都會搬過來）；右鍵 →「造型」→「隨機換成工作台裡的小克」，換成你工作台裡的其他小克（各自原本的樣子）；這項開著的時候會優先用它。

## 語言

右鍵 →「語言」：简体中文 / 繁體中文 / English / 日本語 / 한국어，預設跟著 Windows 的顯示語言。切換後小克會重新啟動一下。想加一種語言：在 `lang.json` 的每一條裡加上翻譯，再在 `lang.py` 的 `LANGS` 裡加一行。

## 性格

只用桌寵的時候，小克也有自己的性格：第一次打開會隨機給它一個（小太陽、嘴硬心軟、慢吞吞、中二勇者、整理控、社恐、小吃貨、小哲學家）。衣櫃的「性格」頁可以換：

- **⚄ 隨機一個**，或者點內建的那幾個；滑鼠移上去，小克會說它是什麼樣的
- **自己寫**：名字 + 一句話描述，點「存」
- **✨ 讓 AI 照你的要求寫一個**：寫好會先填在框裡，你看過點「存」才會換上
- **讓小克照性格寫話**：照這個性格，把 5 個狀態（還有你加的狀態）和被點一下時說的話都重寫一遍，寫好先給你看，勾選的才換
- 「小克挑 3 個」也是照這個性格挑的

## 連著工作台的時候

小克的形象、衣服、性格都跟著工作台走，衣櫃裡就不改了，免得兩邊不一樣。換造型：在工作台裡右鍵小克 →「造型」→「複製給桌寵」，再回來右鍵 →「造型」→「貼上工作台的造型」。想要一隻只在桌寵上用的小克，就在工作台裡新建一隻「桌寵小克」，打扮好再複製過來。不想連了：右鍵 →「連動」→ 把工作台關掉，衣櫃就回來了。

## 換形象：不一定是小克

預設是小克，但桌寵可以換成任何角色：一隻貓、一團史萊姆、你自己 AI 助理的樣子都可以。右鍵 →「造型」→「換形象…」，或是衣櫃的「形象」頁：

- **怎麼分**：把衣服全脫掉還是小克的（狐狸小克、紫色貓貓、水青兔兔……）算「整套」，在「外表」頁；連身體輪廓都不一樣的才算「形象」
- **「＋ 新的」**：✍ 自己畫一隻（虛線框差不多是小克的大小，腳踩在框底；用得最多的顏色就是它的主色）/ ✨ AI 畫 3 隻 / 小克幫你挑 3 隻
- **5 個姿勢自動配好**：著急舉牌、忙碌、悠閒喝茶、歡呼冒星星、睡覺冒 Z。哪個不滿意，點形象頁下面那排小圖，就能在畫布上自己改（例如睡覺時把眼睛閉上）；改壞了就點「換回自動的」
- **衣服照樣能穿**：帽子、耳朵、手上拿的會照它的大小套上去；「顏色」換的是它的主色；體型也能調
- 自己寫的狀態裡改過的樣子，只會用在畫它的那個形象上，換形象不會亂掉
- 點一下打開什麼也能換（右鍵 →「點一下打開」→ 選別的程式），例如換成 Codex 或你常用的 AI 應用程式
- 想從程式碼層面整個改：畫小克的是 `clawd_pet.py` 裡的 `clawd()`，畫其他形象的是 `char_cells()`；改完記得照授權寫清楚改了什麼

## 跟其他小克程式連起來

小克桌寵、「今日小克終未地」工作台、「克講機」小對講機視窗，三樣都能各自單獨使用。裝了哪一樣，小克自己就會找到（靠使用者資料夾裡的「名片」`.clawd\`），第一次發現就自動連上，不用另外設定；**連上了，相關的項目才會出現在選單裡**：

| 裝了什麼 | 小克會怎樣 |
|---|---|
| 只有桌寵 | 狀態、衣櫃、最近在做都能用；點一下打開 Claude 應用程式（或你選的） |
| ＋ 工作台 | 右鍵多了「打開工作台」「貼上工作台的造型」「隨機換成工作台裡的小克」；「點一下打開」可以選工作台（沒開著就幫你開） |
| ＋ 克講機 | 小克手上拿著迷你對講機：點對講機或按兩下小克 = 叫出克講機，長按 = 按住說話 |
| 三樣都有 | 點小克 = 你選的（Claude / 工作台），點對講機 = 克講機 |

右鍵 →「連動」可以手動開關：找不到工作台時，打開開關會讓你選它裝在哪裡；關掉之後就不會再自動連上。

工作台和克講機都是作者的其他作品，會發布在 [作者的 GitHub](https://github.com/Miaomiaomeowmeow)；現在還沒看到的話，過一陣子就會放上來。

## 檔案

| 檔案 | 是什麼 |
|---|---|
| `clawd_pet.py` | 小克本體（只用 Python 內建的東西，不用另外安裝） |
| `pet.py` | 讓小克切換狀態的小指令（也能加狀態、衣服、顏色、整套） |
| `wardrobe.py` | 衣櫃視窗 |
| `lang.py` / `lang.json` | 多語言（介面上的文字和翻譯） |
| `start.bat` | 按兩下啟動 |
| `AI-SETUP.md` / `AI-RULES.md` | 給你的 AI 看的：安裝精靈 / 貼進說明檔的那段 |
| `hooks/` | 自動跟著對話切換的接法 |
| `status.json` / `settings.json` / `recent.json` | 執行時自動產生：目前的狀態 / 你的設定 / 最近幾條 |

小克會在你電腦的使用者資料夾裡放一張「名片」（`.clawd\pet.json`），寫著自己裝在哪裡，工作台靠它找到小克。
